UNIT LEAVE ORGANISER — OFFLINE iPAD VERSION

1. Open index.html in Safari. It runs entirely in the browser and stores data in localStorage on the device.
2. No internet connection is required after the file is available on the iPad.
3. For reliable data transfer, use Reports > JSON Backup regularly. CSV is provided as an Excel-compatible export.
4. Home shows officer counts, today's visibility, and colour-coded mandatory-location coverage gaps.
5. Locations support mandatory/not-mandatory designation and multiple officer allocation.
6. Leave entitlement: 60 Annual Leave + 20 Casual Leave per officer per calendar year. Leave balances are calculated by year, so they reset automatically on 01 January.
7. Leave requests start Pending and have one-tap Accept / Reject controls.
8. Calendar bars can be dragged to shift their period.
9. Reports include Daily Visibility, Monthly Leave/Absence Statement and Mandatory Location Coverage, with print layouts intended for Orderly Room / Adjutant use.

Important: iOS Safari may purge website storage in some storage-management situations. Keep JSON backups in Files/iCloud/another safe location.
